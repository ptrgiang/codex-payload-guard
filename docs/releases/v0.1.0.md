# Codex Payload Guard v0.1.0

Initial public release of Codex Payload Guard — a local-first, read-only byte-budget watchdog for OpenAI Codex sessions.

## Highlights

- inspect Codex rollout sessions and estimate serialized payload composition
- detect risky byte growth that token counters can hide
- capture snapshots and compare payload growth over time
- watch live sessions for rising payload risk
- run deterministic synthetic benchmark scenarios
- export auditable benchmark evidence as JSON and Markdown

## Benchmark evidence

The current full-profile baseline passes all 8 packaged scenarios with 0 false-positive scenarios and a 13.5 MiB median early-warning lead against the benchmark reference thresholds.

These measurements are deterministic benchmark estimates, not claims about exact Codex wire-request byte sizes.

## Safety

Codex Payload Guard is read-only. It does not rewrite Codex rollout JSONL, edit Codex SQLite state, remove images or tool output, force compaction, or replay side effects.

## Install

For this first GitHub release, install directly from the tagged source:

```bash
pip install "git+https://github.com/ptrgiang/codex-payload-guard.git@v0.1.0"
```

Or download the wheel attached to the GitHub Release and install it with `pip`.

Then:

```bash
cpg --version
cpg scan
cpg inspect --latest
cpg watch --latest
cpg benchmark
```

PyPI publication is not part of v0.1.0.

## Release artifacts

The release workflow validates the tag against the package version, builds wheel and sdist artifacts, checks package metadata, installs the wheel into a clean virtual environment, runs a benchmark smoke test, and attaches the distributions to the GitHub Release. The benchmark evidence workflow separately attaches the full JSON and Markdown evidence reports.
